# Flow — Official Landing Page

> O Sistema Operacional da Sua Rotina com IA que replaneja seu dia.

Landing page oficial do **Flow**, aplicativo desktop de gestão de rotina, produtividade de alta performance e bem-estar acústico.

## 🚀 Tecnologias

- **Framework**: [React 19](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/)
- **Estilização**: [Tailwind CSS v4](https://tailwindcss.com/)
- **WebGL & Animações**: [OGL](https://github.com/oframe/ogl), [GSAP](https://greensock.com/gsap/), [Framer Motion](https://www.framer.com/motion/)
- **Ícones**: [Lucide React](https://lucide.dev/)
- **Áudio**: Web Audio API nativa com síntese de ondas harmônicas em 528Hz (Tigela Tibetana pura) e micro-interações sonoras táteis

## 💎 Recursos da Landing Page

- **Hero 3D com WebGL**: Efeito de fundo *MoltenMetal* em tempo real com shaders WebGL 2.0 e *DepthText* volumétrico.
- **Áudio Sensorial Interativo**: Player de ressonâncias binaurais com controle de volume analógico (*WakeSlider*) e síntese em tempo real.
- **Simulador Interativo**: Demonstração visual do aplicativo Flow Desktop v1.0.
- **Branch Feature Explorer**: Navegador ramificado com visualização hierárquica em SVG e preview de telas.
- **Comparativo Direto**: Tabela interativa destacando os diferenciais do Flow contra ferramentas legadas.
- **FAQ Interativo**: Accordion com transições suaves e explicações aprofundadas.
- **Download Direto do Desktop**: Links otimizados com headers de download para o instalador Windows (`Flow_Setup_x64.exe`).

## 🛠️ Como Executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
